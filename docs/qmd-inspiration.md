# QMD inspiration

This project borrows a few system-design ideas associated with QMD: local-first retrieval, typed lexical/vector/hypothetical queries, explicit intent/context, rank fusion, bounded expensive ranking, and stable document retrieval primitives.

It intentionally does **not** implement QMD's full collection management, MCP surface, or broader feature set. The goal is a small RAG retrieval service whose design choices are easy to inspect in a portfolio review.
